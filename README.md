# Apex Vista

A full-stack Flask e-commerce website built with Python, Flask, SQLite, HTML, CSS, and JavaScript, with Paystack payment integration.

## Features

- User registration and login
- Product catalogue
- Product search
- Product details pages
- Shopping cart
- Wishlist
- Quantity management
- Checkout
- Paystack payment integration
- Order history
- Order numbers and order summaries
- Responsive e-commerce interface
- Toast notifications and interactive UI

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Paystack API
- Git & GitHub
